# Changelog

## 0.1.0 — 2026-10-01
- First release: wrapper for Devin Desktop and Devin CLI with pull on start / push on exit.
- Per-session merge of `sessions.db`, sidebar index rows from `state.vscdb`, ACP message stores,
  legacy Cascade chats, memories, plans, settings.
- Cross-PC lock, SHA-256 check of downloaded snapshots, schema-version guard, local backups.
- English and Italian notifications.
